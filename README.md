# 小學習冒險｜小一～小三・三科練習場

「小學習冒險」是一套給國小一～三年級兒童使用的互動練習工具，整合國文、數學與英文，以每天約 10 分鐘、每回最多 10 題的方式進行。

**線上使用：**  
https://joelee2017.github.io/Junior_Learning_Adventure/

## 目前版本

- 版本：1.6
- 更新日期：2026-09-10
- 主程式：單一 HTML 檔案
- 適用裝置：Windows、macOS、平板與手機的現代瀏覽器

## 主要功能

- 國文、數學、英文分開練習與記錄。
- 每科分為「小一／小二／小三」及「入門／熟練／綜合」。
- 家長可以依孩子目前的學習狀況自行選擇練習階段。
- 每回最多 10 題，適合短時間練習。
- 提供單項能力強化。
- 提供「我的弱項」練習。
- 練習時會變換選擇題的選項位置。
- 系統會優先安排近期較少出現的題目，減少短時間內反覆遇到相同題目。
- 提供作答紀錄與家長查看的進度資訊。
- 國文提供基礎國字書寫活動。
- 不需要登入、伺服器或安裝程式，直接開啟 HTML 即可使用。

## 使用方式

1. 開啟主程式 HTML。
2. 選擇國文、數學或英文。
3. 選擇適合孩子的年級與階段。
4. 開始 10 題練習。
5. 完成後查看結果，再依孩子的實際表現決定下一次是否繼續目前階段或更換階段。

系統提供的是練習紀錄與參考資訊，階段是否需要調整由家長依孩子的實際學習狀況判斷。

## 設計方向

- 一次只處理一題，降低畫面干擾。
- 不使用倒數計時。
- 不使用排行榜。
- 不以答錯扣分。
- 正確率與作答紀錄用於了解練習狀況，不作為孩子的能力標籤。
- 適合家長陪同，也適合孩子逐漸自行操作。

## 資料與隱私

本工具以單機使用為主要設計方向，練習紀錄儲存在使用者的瀏覽器中。

- 不需要建立帳號。
- 不需要輸入孩子姓名等個人資料。
- 不依賴外部題庫或遠端 JavaScript 才能進行基本練習。
- 若清除瀏覽器的網站資料，可能會一併清除本機練習紀錄。

## 專案定位

本工具是家庭學習與練習用途，不取代學校課程、教師判斷或正式評量，也不宣稱完全對應特定出版社或學校的教學進度。
