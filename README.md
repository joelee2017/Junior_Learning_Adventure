# 小學習冒險｜小一～小二三科練習場

「小學習冒險」是一套給國小一、二年級兒童使用的互動練習工具，整合國文、數學與英文，以每天約 10 分鐘、每回最多 10 題的方式進行。

**[點此立即線上刷題](https://joelee2017.github.io/Junior_Learning_Adventure/)**

## 目前版本

- 版本：1.1
- 更新日期：2026-09-02
- 題庫總數：202 題
- 適用裝置：Windows、macOS、平板與手機的現代瀏覽器

## 題庫內容

| 科目 | 題數 | 主要內容 |
|---|---:|---|
| 國文 | 82 | 注音、零～十數字國字、詞語、句子、閱讀與推理 |
| 數學 | 60 | 數量、加減法、時間、圖形、錢幣、乘法與應用題 |
| 英文 | 60 | 字母、生活單字、簡單句型、自然發音與閱讀 |
| 合計 | 202 | 三科各有 6 個能力等級 |

國文 LEVEL 01 另外包含「數字國字」單元：

- `0 → 零` 到 `10 → 十`
- `零 → 0` 到 `十 → 10`
- 共 22 題雙向配對

## 主要功能

- 國文、數學、英文三科獨立進度
- 每日 10 題練習
- 6 級能力階梯
- 指定等級練習
- 單項強化
- 我的弱項
- 錯題訂正
- 全部題目與答案瀏覽
- 每回及累計學習紀錄
- 80% 達標判斷
- 英文語音朗讀
- 學習紀錄匯出與匯入
- 手機、平板與桌機響應式版面
- 使用瀏覽器本機儲存，不上傳作答資料

## 快速開始

1. 下載 `小學習冒險_小一小二三科練習場.html`。
2. 使用 Chrome、Edge、Firefox 或 Safari 開啟。
3. 在首頁選擇國文、數學或英文。
4. 按下「開始 10 題」，即可進行當日練習。

也可以將 HTML 放到 GitHub Pages，作為純靜態網站使用。

## 資料保存

作答紀錄保存在目前瀏覽器的 `localStorage`。因此：

- 更換瀏覽器或裝置時，紀錄不會自動同步。
- 清除瀏覽器網站資料，可能同時清除學習紀錄。
- 建議定期到「家長專區」匯出 JSON 備份。
- 在另一台裝置使用時，可匯入先前的 JSON 紀錄。

## 設計原則

- 一次只顯示一題，降低畫面干擾。
- 底部固定顯示結束、上一題、題號與下一題。
- 答錯後提供正確答案與簡短說明，再於結果頁進行錯題訂正。
- 正確率作為調整練習的線索，不作為孩子的能力標籤。
- 不使用倒數計時、失敗音效或答錯扣分。
